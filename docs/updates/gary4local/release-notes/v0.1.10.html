gary4local v0.1.10

Stable Audio 3 LoRA training arrives on the macOS localhost stack for the Gary4JUCE 4.0.1 release train.

Highlights

  • Train SA3 LoRAs directly from the gary4local control center on Apple Silicon using our MLX port with parity to the Dada Bots underfit workflow.
  • Edit optional text-sidecar prompts, monitor auto-scrolling logs, preserve job status across app restarts, and cancel preprocessing or training cleanly.
  • Automatically register completed .safetensors adapters for immediate use in gary4juce.
  • Keeps the shipped app bundle leaner by trimming SA3 development-only files while preserving the full local training runtime.

Recommended Companion

  • gary4juce v4.0.1
  • Release page: https://github.com/betweentwomidnights/gary4juce/releases/tag/v4.0.1

Notes

  • This build is distributed outside the Mac App Store as a notarized DMG.
  • Sparkle signatures are included for the in-app updater flow.
  • The SA3 training path is currently vendored here while upstream integration work with the underfit project is still in progress.
  • SA3 inference and training continue to assume Apple Silicon as the supported production target for the MLX backend.
