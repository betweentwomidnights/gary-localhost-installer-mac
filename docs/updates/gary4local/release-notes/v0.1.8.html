gary4local v0.1.8

Hotfix release for the 0.1.7 Carey parity build that updates the recommended gary4juce pairing shown inside About gary4local.

Highlights

  • Updates the About dialog so gary4local now recommends the correct companion build: gary4juce v3.0.7-mac.
  • Links the companion release button directly to the matching v3.0.7-mac GitHub release tag.
  • Adds an explicit release-checklist reminder that the About dialog companion version should be reviewed on every macOS release.

Recommended Companion

  • gary4juce v3.0.7-mac
  • Release page: https://github.com/betweentwomidnights/gary4juce/releases/tag/v3.0.7-mac
