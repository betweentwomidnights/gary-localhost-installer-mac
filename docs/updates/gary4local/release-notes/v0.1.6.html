gary4local v0.1.6

Apple Silicon localhost update with Carey local LoRA management, caption-pool building, and the mac pairing work needed for gary4juce v3.0.5-mac.

Highlights

  • Adds the new Carey local LoRA manager in gary4local, including local adapter registry generation and caption-pool building for gary4juce.
  • Supports separate checkpoint folders and captions/source folders so Side-Step style LoRA training outputs import cleanly.
  • Adds standard-versus-XL LoRA family filtering so gary4juce only shows adapters that match the current Carey mode.
  • Improves localhost parity by exposing live LoRA and caption catalogs to gary4juce while Carey is running.
  • Hardens the Carey adapter lifecycle on macOS across MLX and MPS testing paths for the new local LoRA workflow.

Recommended Companion

  • gary4juce v3.0.5-mac
  • Release page: https://github.com/betweentwomidnights/gary4juce/releases/tag/v3.0.5-mac

Notes

  • This build is distributed outside the Mac App Store as a notarized DMG.
  • Sparkle signatures are included for the in-app updater flow.
  • On lower-memory Apple Silicon systems, Carey xl-base with LoRAs can be noticeably slower than xl-turbo, especially under screen sharing.
