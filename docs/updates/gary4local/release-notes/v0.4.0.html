gary4local v0.4.0

version jumps from 0.2.0 to line up with the windows build, and pairs with gary4juce v5.0.0-mac.

likely the last mac-specific installer update

we're moving toward one cross-platform gary4local backed by fully native C++ services, so this separate mac app probably won't get many more releases. the replacement and its migration steps aren't out yet. keep using this app for now.

new

  • YuE2 is here, through yuey.cpp v0.2.2's native Metal/CPU runtime. no python environment to build: install the runtime and a GGUF model from yuey's row. the model unloads after each generation.
  • sa3 honors gary4juce's ending choice on generate and continue: ends here or keeps going for another continuation. returned audio keeps the length you asked for.
  • local sa3 and carey accept up to 380 seconds. sa3 continuation counts the source plus the added audio within that total.
  • foundation's gary_fallback and royalcities profiles now reach the MLX sampler for generation and audio-to-audio.
  • carey offers optimized MLX model downloads. existing models keep working, and cleaning up the old ones is optional.
  • cached sa3 models load without an online login check. the SAME-L decoder squeak fix has its own download and stays opt-in.

also from the unreleased v0.2.1

  • gary and terry accept a seed and return the one they used.
  • sa3 continuations crossfade into a regenerated overlap instead of hard-splicing.

your existing installation

nothing is deleted or moved automatically. legacy carey models keep working, and custom runtime storage is not part of this mac release.

compatible with gary4juce v5.0.0-mac. notarized DMG with sparkle signatures for the in-app updater.
