gary4local v0.2.1

an incremental compatibility release for the newest mac gary4juce, deliberately smaller than the ongoing full windows-parity work.

new

  • gary and terry now accept a seed, return the seed they actually used, and support repeatable requests from the new plugin controls.
  • sa3 continuations preserve the original source and crossfade into a regenerated overlap, matching the smoother windows continuation path.
  • sa3 can optionally download and merge the SAME-L decoder squeak fix into its native MLX decoder without taking a user LoRA slot.

not in this release

custom runtime storage and cleanup, plus custom ACE-Step MLX model work, remain on the broader mac-parity track.

compatible with gary4juce v4.0.14-mac. notarized DMG with sparkle signatures for the in-app updater.
