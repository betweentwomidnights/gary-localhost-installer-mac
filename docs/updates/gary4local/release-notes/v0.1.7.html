gary4local v0.1.7

Apple Silicon localhost update that brings the mac Carey stack into parity with the latest Windows-side ACE-Step behavior and refreshes the packaged updater build for Sparkle delivery.

Highlights

  • Updates Carey cover generation to use the newer cover-nofsq path instead of the older standard cover mode.
  • Switches Carey lego mode over to the upstream ACE-Step implementation and removes the older custom marker-based workaround.
  • Keeps lego mode pinned to acestep-v15-base even when the Carey XL toggle is enabled, matching the intended upstream behavior.
  • Fixes the macOS Carey predownload and required-files UI so offline installs still fetch the regular lego base checkpoint when the main Carey family is set to XL.
  • Adds focused wrapper and ACE-Step regression coverage around the new Carey routing, task handling, and repaint behavior.

Recommended Companion

  • gary4juce v3.0.3-mac
  • Release page: https://github.com/betweentwomidnights/gary4juce/releases

Notes

  • This build is distributed outside the Mac App Store as a notarized DMG.
  • Sparkle signatures are included for the in-app updater flow.
  • Carey lego mode now intentionally ignores the XL model toggle and always uses the regular base checkpoint.
