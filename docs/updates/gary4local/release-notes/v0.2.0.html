gary4local v0.2.0

version jumps from 0.1.11 to line up with the windows build. this one is all about the stable audio 3 LoRA trainer.

new

  • auto-label a whole folder with ace-step's captioner, plus bpm and key suggestions from our own analysis helpers.
  • layer scope defaults to 169 layers instead of 229. faster, smaller file, no difference we could hear. "train everything" is still there.
  • sa3 starts in under 4 seconds instead of ~25. converted weights are cached now.
  • switching or adding a lora takes under a second instead of ~20.
  • the shared trigger word stays out of your sidecar files and dice prompts.
  • experimental loudness fix for datasets with uneven volume.

heads up

if you have an sa3 lora that hums or drones at higher strength, retrain it. training pins to the stable audio 3 base model now and refuses anything else — the wrong one is what caused that.

not yet

  • full-track training. mlx wants way more memory than the windows build does and we want to know why first. 23-second crops still make loras that generate several minutes fine.
  • hugging face's hosted mlx models. byte-identical to what we convert locally, so it's only a smaller install — not worth a ~9 gb re-download until we can clean up after ourselves properly.

compatible with gary4juce v4.0.7-mac. notarized DMG with sparkle signatures for the in-app updater.
