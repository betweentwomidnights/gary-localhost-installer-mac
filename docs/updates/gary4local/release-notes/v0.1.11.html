gary4local v0.1.11

You can now train an ACE-Step LoRA directly inside gary4local, done in MLX, as part of the Gary4JUCE 4.0.4-mac release train.

Highlights

  • Train an ACE-Step LoRA directly inside gary4local on the pure MLX path instead of bouncing out to a separate training flow.
  • The new mac UI covers dataset prep, prompt-side editing, logs, cancellation, and the rest of the local Carey training workflow.
  • The genre_ratio follow-up fix is also included here, with the needed double pre-encode behavior so the training UI and dice prompt behavior stay aligned with PC parity.

Recommended Companion

  • gary4juce v4.0.4-mac
  • Release page: https://github.com/betweentwomidnights/gary4juce/releases/tag/v4.0.4-mac

Notes

  • This build is distributed outside the Mac App Store as a notarized DMG.
  • Sparkle signatures are included for the in-app updater flow.
  • The paired gary4juce v4.0.4-mac release should go live alongside this build so the recommended companion link resolves immediately.
  • Carey, Stable Audio 3, and the other localhost runtimes continue to target Apple Silicon as the supported production path for macOS.
