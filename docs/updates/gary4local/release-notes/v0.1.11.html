gary4local v0.1.11

The macOS localhost stack now ships the Carey parity fixes and training UX updates for the Gary4JUCE 4.0.4-mac release train.

Highlights

  • Carey ACE-Step training on macOS now matches the PC flow more closely, including the genre-versus-caption variant behavior driven by genre_ratio.
  • ACE-Step tracks are pre-encoded twice where needed so the training UI, dice prompt behavior, and per-epoch prompt selection stay aligned.
  • The recent Carey service and ACE-Step LoRA training UI work remains included in the signed macOS release path.

Recommended Companion

  • gary4juce v4.0.4-mac
  • Release page: https://github.com/betweentwomidnights/gary4juce/releases/tag/v4.0.4-mac

Notes

  • This build is distributed outside the Mac App Store as a notarized DMG.
  • Sparkle signatures are included for the in-app updater flow.
  • The paired gary4juce v4.0.4-mac release should go live alongside this build so the recommended companion link resolves immediately.
  • Carey, Stable Audio 3, and the other localhost runtimes continue to target Apple Silicon as the supported production path for macOS.
